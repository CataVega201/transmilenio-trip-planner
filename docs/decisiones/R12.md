# R12: tabla hash compartida

## Responsable y comportamiento

Responsable: Mariana Parra. Issue #7. 

`TablaHash` ofrece `guardar(clave, valor)`, `obtener(clave, defecto=None)`,
`eliminar(clave)` y `pares()`. Guardar reemplaza el valor de una clave
existente. Eliminar devuelve `True` si encontró la clave y `False` si no.
`pares()` itera tuplas `(clave, valor)`.

## Cómo funciona

Una lista de cubetas; cada cubeta es una lista de pares `(clave, valor)`.
La posición de una clave es `hash(clave) % len(self._cubetas)`. Si dos
claves caen en la misma cubeta (colisión), conviven en esa lista.

## Alternativa considerada

Direccionamiento abierto: ante una colisión, buscar otra cubeta libre.
Elegí listas por cubeta porque basta buscar y eliminar el elemento en su cubeta. Además, las colisiones se resuelven guardando las claves en la misma lista, lo que simplifica la inserción.

## Complejidad (Big O)

n = número de pares guardados. B = número de cubetas actuales.

| Operación | Caso promedio | Peor caso | Por qué |
|---|---|---|---|
| `obtener` | O(1) | O(n) | Solo revisa una cubeta; el peor caso es que todas las claves caigan en la misma |
| `guardar` | O(1) esperado y amortizado | O(n) | El peor caso ocurre si hay colision total en una sola cubeta y tambien cuando hay que redimensionar |
| `eliminar` | O(1) | O(n) | Accede a la cubeta en O(1) y busca y elimina en la lista, el peor caso recorre los n elementos si colisionaron todos juntos |
| `pares` | O(B + n) | O(B + n) | Obligatoriamente recorre todas las cubetas y todo lo contenido en ellas |
| `_redimensionar` | O(n) | O(n) | Recoloca todos los pares |

## Variables

- `_cubetas`: Una lista de listas, es la estructura principal de almacenamiento, cada cubeta guarda los pares (clave, valor)
- `_cantidad`: Un número entero que lleva el registro del total de pares almacenados en la tabla
- `posicion`: El valor de aplicar hash(clave) % len(self._cubetas), este determina en que cubeta se debe buscar

## Límites

- Capacidad inicial: 8 cubetas.
- Se duplica cuando la carga pasaría de 0.79
- No se contrae al eliminar. Evita redimensionar una y otra vez, pero deja cubetas vacias que pares() sigue recorriendo
- Las claves deben ser hashables: una lista da `TypeError`.
- El orden de pares() no esta garantizado y puede cambiar entre ejecuciones. Quien necesite orden debe ordenar los resultados.

## Ejemplo

```python
tabla.guardar("portal", "Museo")
tabla.guardar("portal", "Museo de la Ciencia")
tabla.obtener("portal")       # "Museo de la Ciencia"
tabla.eliminar("portal")      # True
tabla.obtener("portal", "-")  # "-"
```
