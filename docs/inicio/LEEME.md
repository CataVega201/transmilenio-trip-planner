# Empieza aquí

1. Acepta la invitación con tu propia cuenta y completa la [instalación](INSTALACION.md).
2. Abre tu ficha: [Catalina](CATALINA.md), [Mariana](MARIANA.md), [Alejandro](ALEJANDRO.md) o [Daniel](DANIEL.md).
3. Pega en ChatGPT el prompt inicial de [Trabajo con IA](TRABAJO_CON_IA.md) y después el encargo de tu ficha. Trabaja en un bloque cada vez.

**Para Catalina.** En [Configuración del repositorio](https://github.com/CataVega201/transmilenio-trip-planner/settings/access), abre **Colaboradores → Añadir personas** (Collaborators → Add people). Busca por usuario o correo, verifica el perfil y envía la invitación. Repite para cada integrante. Cada persona acepta desde la notificación o el correo con su propia cuenta.

**Para todos.** Estas guías se pueden leer en GitHub desde la rama `docs/guias-equipo` antes de su integración. Las ramas de código se crean desde `main` actualizado. Si una guía falta en tu copia, la IA puede leerla con `git show origin/docs/guias-equipo:docs/inicio/MARIANA.md` cambiando el nombre por el tuyo. No hace falta cambiar a la rama de documentación para leerla.
